**COSAS QUE TIENE ACTUALMENTE**

* Un editor de microbios
* Un editor de Plantas en prototipo
* el prototipo de etapa espacial
* generacion galactica con algunos tipos (elipctica espiral lenticular e irregular)
* prototipo de etapa microbio (a veces llamada celula)
* Modding Basico (partes personalizadas)
* un monton de clases que deje como future proofing

COSAS QUE NO SE AÑADIRAN:
1. Multijugador
2. compras en el juego
3. hiperrealismo
